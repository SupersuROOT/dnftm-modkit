DNFTM Mod 编辑器 v0.5.0（支持 ModLoader 0.5.10 的全部功能）
=====================

用浏览器打开的可视化编辑器，用来制作 Do Not Feed the Monkeys 的新笼子。
不需要安装，可以脱机使用。


怎么打开
--------
用 Chrome 或 Edge 打开 Editor 文件夹里的 index.html（直接双击即可）。
  * Chrome / Edge：可以直接读写游戏的 Mods 文件夹（按「📂 打开文件夹」）。
  * Firefox 等其他浏览器：用「📥 导入」读取，改完用「⬇ 导出 zip」，
    再把 zip 解压缩到游戏文件夹。

Editor 文件夹里的文件要放在一起（index.html、editor.css、core.js、ui.js、
catalog.js、example.js），不要只拷贝 index.html。


基本流程
--------
1. 先用 DNFTM-ModInstaller.exe 安装 mod loader（只需要做一次）。
2. 打开编辑器 →「📂 打开文件夹」→ 选游戏文件夹（dnftm.exe 所在处）。
3. 「＋ 添加 Mod」创建你的 mod，再按左侧的「＋ 添加笼子」：
   输入 id、从预览图挑选场景、选择镜头数、画面风格和笔记本版型。
4. 在各分页编辑：
   基本信息  难度、购买顺序、画面风格、镜头与对象清单
   剧情      场景（几点开始、接到哪个场景）与动作（说话、移动、动画…）
   预设动作  可以重复使用的一串动作
   关键字    玩家可以点击、写进笔记本、拿去搜索的词，以及搜索结果新闻
   笔记本    把关键字分配到笔记本页的字段、选择要保留的圆圈
   文本      所有英文和简体中文的对照表（可一键繁→简）
   素材      导入自己的 PNG、角色动画、夜晚与夜视图层（v0.3）
   互动      新闻、邮件与任务、录像投稿、聊天、电话、物品、寄送商品、自订事件（v0.3）
   原始 JSON 其他高端内容
5. 右侧「检查结果」的 ❌ 全部清除后，按「💾 保存」（或 Ctrl+S）。
6. 开新游戏测试。出问题时请查看游戏文件夹里的 Mods\ModLoader.log。

首页可以加载两个范例：
  夜读者    使用游戏内置场景的剧情笼子
  幽灵房间  全部用自己的 PNG 画的笼子（自订素材、逐格动画、夜晚遮罩、夜视血字）


v0.5.0
------
支持 ModLoader 0.5.3～0.5.10 新增的全部功能，不必再手改 JSON：
* Mod 页：最低 ModLoader 版本（minLoader）。编辑器会依用到的功能算出需要的版本，保存时自动调高。
* 关键字：「是地址」（MART 寄送）、「一起写进笔记本的关键字」（addWords）、「点按钮时拨打」（电话号码）。
* 笔记本：
  - 每个字可勾「可选」（main：能在电话、聊天、俱乐部任务里选）、「大写」，以及电话/聊天「按钮」；
  - 推理「？」：3 个答案、出现条件（至少几个字、只算哪些字、一定要有哪些字）；
  - 自动写入（mainWord）、圆圈之间的箭头；
  - 调整版面：复制元素（例如多一个电话方框）、移动、放大缩小（sx、sy）。上方示意图即时显示结果。
* 互动 → 物品：「物品架上的物件」（ModLoader 0.5.10）。mod 的物品没有自己的物件时，玩家收到会卡住，检查结果会报错。
* 电话、聊天、上门对话：
  - 选项可以「📓 打开笔记本」接到关键字回答节点；
  - 关键字回答加入 none（不选／挂断）；
  - 聊天的结束节点可以勾「在这里结束」；
  - 上门对话可以设「整段对话结束时的事件」（例如亲手送礼）。
* 修正：以前每个对话节点都会写入空的关键字表（keywords），可能让一般选项不显示；现在只在真的加了关键字回答时才写入。


v0.4.1
------
* 几乎每个看不懂的字段旁边都有 ⓘ：鼠标移上去看说明，点一下弹出完整说明。
  特别难懂的（例如「摄像头画面风格」）直接在字段下方写了一行白话说明。
* 镜头灯：场景有角色活动却没有「🔴 镜头灯闪烁」时，检查结果会提醒；
  剧情分页的「💡 一键加入镜头灯」会在场景开头加入闪烁、结尾加入停止。
* 范例「幽灵房间」补上了镜头灯。


v0.4 新功能
-----------
* 编辑器界面改为简体中文（和游戏的中文一致）。
* 模组不再改变原版游戏：游戏主菜单的笔记本上多了「模组」，进去勾选要玩的模组再开新游戏；
  不勾选就是原版。继续游戏会自动使用存档当时的模组。
* 素材对象可以设为「可点击关键字」：玩家在监视画面点击它就能获得关键字（鼠标移上去会出现黄色描边）。
* 浏览器搜索结果新增：百科页面、Metayou 社交主页、电话簿条目、地图、网页（自由排版）。
* 新事件：有人敲门（含开门后的对话）、日历事件、冰箱便条、游戏结局、插入剧情动作。
* 互动分页新增「结局」：定义游戏结束时的结局总结页，再用事件「加入结局总结」加入。


v0.3 新功能
-----------
素材分页
  * 「＋ 导入 PNG」把图片放进 Mods\<你的Mod>\art\<笼子>\。
  * 添加对象：背景、角色（有动画）、道具／前景、夜晚遮罩、只在夜视中看得到。
  * 角色动画可以用「多张 PNG」或「sprite sheet」（填每格宽高，编辑器会切格并标上编号）。
  * 每段动画可设置 fps 与是否循环；旁边的小窗口会即时播放。
  * 「清空原模板对象」= 完全自订的场景；不勾选则是在原场景上加东西。
  * 预览可切换 白天／夜晚／夜晚+夜视。
  * 注意：自订对象在游戏中一开始都是显示的，要晚点登场请在起始场景加「隐藏」。

剧情分页的即时预览
  * 每个场景都有 ▶ 预览：角色移动、对白泡泡、动画、显示隐藏、镜头灯都会仿真，
    可以拖动时间轴、调速度、切换简中／英文与白天／夜晚／夜视。
  * 会先把同一条场景链前面的场景快转，所以起始位置和游戏里一致。
  * 内置角色显示默认姿势并标出目前的动画名称；自订素材会播放真正的影格。
  * 条件 if / ifNot 在预览中一律当作成立。

互动分页
  新闻        报纸新闻（用事件「刊登新闻」加入）
  邮件与任务  一般邮件、任务精灵（mission / missionCorrect / missionFail，游戏会自动寄出任务）
  录像投稿    玩家寄给 Shock.tv 的结果；在剧情中用「🎥 标记可投稿」标出有价值的片段
  聊天        聊天对象（头像、暱称、上线时间、解锁关键字）与对话树
  电话        对话树；用事件「对方来电」或「开放拨打」
  物品        玩家拿到、可以卖掉的东西
  寄送商品    玩家从 MART 买东西寄到笼子地址时发生的事
  自订事件    有名字的一组事件，剧情中用「⚡ 触发自订事件」调用
  事件编辑器支持：金钱、业力、变量、切换场景、新闻、邮件、聊天、电话、物品、邮差送货、
  结案、健康／睡眠／饥饿等，并可设置「几天后几点」与条件。


小技巧
------
* 动作的「📍 在画面上选」可以直接在镜头画面上点击位置。
  画面是 252×174 像素：x 从左到右，y 从下往上；负数或超过范围代表画面外，
  可用来让角色从画面外走进来。
* 对白里用 [关键字id]显示文本[/关键字id] 标出可以点击的关键字。
* 游戏的中文本型只有简体字（约 2600 字），游戏画不出来的字会被标成红色。
* 精灵产生的「start」场景会先把模板里原本的角色隐藏起来；
  要让角色登场，请先用「显示」，再用「瞬间定位」。
* 目前的美术都借用游戏内置的笼子场景。


注意
----
catalog.js 里有从游戏截取的场景预览图和数据，仅供已购买游戏的玩家自己使用，
请不要公开散布。分享 mod 时，只要分享 Mods 文件夹里你自己的 mod 即可。
