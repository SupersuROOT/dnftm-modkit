Do Not Feed the Monkeys - custom cages, release 1.0
===================================================

Other languages: 说明_简体中文.txt (Simplified Chinese), 說明_繁體中文.txt (Traditional Chinese)

An unofficial fan mod for players who own Do Not Feed the Monkeys (Windows, Steam or GOG).
It contains two custom cages, the installer 0.5.10 and ModLoader 0.5.10:

  Moth Screen v2.5    A 7-day story cage. Through the Club's relay you watch the desktop of a 19-year-old
                      beginner hacker and hear his microphone. He took a job: find out where a woman lives...
                      Searches, deductions, phone calls, chat and several endings.
                      Details: Mods\MothScreen\README_飛蛾螢幕.txt (Chinese)
  Going Down v0.6.2   The CCTV camera of an apartment-block lift. No keywords; just watch.
                      Details: Mods\LiftCam\README_下行中.txt (Chinese)

Both cages are in English and Simplified Chinese.

Install (once)
--------------
1. Copy ALL files of this folder into the game folder (where dnftm.exe is):
     DNFTM-ModInstaller.exe, DNFTM-ModInstaller.exe.config, Mono.Cecil.dll, DNFTMModLoader.dll, the Mods folder
   Finding the game folder: Steam: right-click the game > Manage > Browse local files.
   GOG Galaxy: game page > Manage installation > Show folder.
2. Double-click DNFTM-ModInstaller.exe, type 1 and press Enter (installs the loader).
   If Windows shows a warning, choose "More info" > "Run anyway".
   The first line reads "DNFTM Mod Installer 0.5.10 (ModLoader 0.5.10)", the last one "Installed ModLoader 0.5.10".
3. Start the game. The main-menu notebook has a new MODS page:
     * at the bottom it must say "ModLoader 0.5.10". If it does not, steps 1-2 did not work.
     * tick the cages you want (all is fine), go back with the arrow at the bottom left and start a NEW GAME.
   Cages are chosen when a new game starts; changing them later needs a new game.
   Installed an older version before? Do steps 1-2 again and start a new game (old saves may show an incomplete notebook).

Tips
----
* Moth Screen's notebook: when a circle has enough words, "???" appears next to it. Click it to make a deduction;
  the deduced words can be searched, used in phone calls and in the chat.
  Some web pages are only found by searching two words together.
* Moth Screen cannot be recorded (the record button does nothing there). This is on purpose.

Uninstall
---------
Run DNFTM-ModInstaller.exe again and type 2 (uninstall): the game is restored. Then delete the Mods folder.
(On Steam, "Verify integrity of game files" also restores the game.)

Problems
--------
Please send the file Mods\ModLoader.log from the game folder, with the day and what you were doing.
