# Going Down / 下行中 — 故事大綱（籠子 id `liftCam`，模組資料夾 `LiftCam`）

**一句話**：俱樂部給你一台舊公寓「拉克斯珀公寓」（Larkspur Court，12 層）電梯裡的監視器。
每天都有住戶進出、聊天、吵架、跳舞——但這個籠子**沒有任何關鍵字**。筆記本頁是空的。
第 6 天電梯困人，第 7 天電梯被封，畫面只剩關燈的電梯和偶爾的訊號故障。新聞揭露原因：
維修公司「UpRight 電梯」多年偽造檢驗，全市 40 台電梯被勒令停用。

- 長度：7 天，每天 4–6 段場景。
- 基調：荒誕幽默 + 微微不安（不解釋的小怪事：深夜電梯自己跑、按不存在的 13 樓的灰衣人）。
- 線索：**完全零關鍵字**。人名、樓層、公司名都只是普通文字，不能點、不能撥、不能寄 MART。
- 語言：英文 + 簡體中文（遊戲字型限制）。

## 畫面（俯拍，最吃美術的部分）

監視器裝在電梯**後方天花板角落**，斜俯拍（約 70°）朝向門：

```

│ CAM-E2 LARKSPUR CT      [樓層顯示 09]   REC│  ← 上：門牆，兩扇不鏽鋼門 + 樓層顯示
│        ╲  ┌──────┬──────┐  ╱  [按鈕面板]   │
│         ╲ │  門  │  門  │ ╱               │
│ 側牆扶手 ╲└──────┴──────┘╱  側牆扶手       │
│           ╲  地板（梯形）╱                 │  ← 人站在中段：看到頭頂 + 肩膀
│            ╲            ╱                  │
│  （左下角保持暗色：遊戲在此寫 RECORDING）    │
└────────────────────────────────────────────┘
```

- 俯拍角色要**靠頭頂辨認**：髮型/帽子/禿頂/耳機/包包/手上的東西就是角色辨識度。
- 物件：`car`（電梯廂背景：日光/夜間/全暗 三種）、`doors`（開/關/半開動畫）、`display`（樓層數字，含 `13`、`--`、熄滅）、
  每個角色一個 sprite（走路 2 格、站立、說話、特殊動作）、`dog`、`props`（紙箱、拖把桶、衣櫃紙箱）、
  `glitch`（訊號故障條紋、畫面撕裂、雜訊）、`overlay`（攝像頭時間戳、暗角、掃描線）、`ghost`（僅夜視可見，見下）。
- 鏡頭效果複製原作 `elevatorCrusoe`（原作也有電梯籠子，可當美術參考，但劇情與構圖不同）。
